## 🏛️ Descripción del Proyecto

Este repositorio contiene la **Homepage interactiva del Portafolio Digital**, estructurada estrictamente bajo las pautas de la **Ficha de Entrega EC1** y orientada a responder con profundidad y honestidad intelectual la interrogante central del Módulo 1:

> *«¿Qué tipo de profesional queremos ser en un país donde la transgresión ética muchas veces parece normalizada o incluso recompensada?»*

El proyecto unifica la perspectiva de **Arquitectura de Interiores** y de **Ingeniería Empresarial y de Sistemas**, articulando la dimensión del espacio físico construido con la de la infraestructura invisible de datos y algoritmos.

## 🚀 Despliegue en GitHub y Vercel

### Paso 1: Subir a GitHub
1. Abre tu terminal en la carpeta del proyecto:
   ```bash
   git init
   git add .
   git commit -m "feat: Homepage interactiva del Manifiesto de Identidad Ética (EC1)"
   ```
2. Crea un nuevo repositorio en [GitHub](https://github.com/new) con el nombre `huella-profesional-portafolio` (público).
3. Conecta y empuja el código:
   ```bash
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/huella-profesional-portafolio.git
   git push -u origin main
   ```

### Paso 2: Desplegar en Vercel
1. Ingresa a [vercel.com](https://vercel.com) e inicia sesión con tu cuenta de GitHub.
2. Haz clic en **"Add New..."** > **"Project"**.
3. Selecciona tu repositorio `huella-profesional-portafolio` e impórtalo.
4. Vercel detectará automáticamente que es un proyecto web estático con `index.html`. Haz clic en **"Deploy"**.
5. ¡Listo! En menos de 30 segundos tendrás tu URL pública (ejemplo: `https://huella-profesional-portafolio.vercel.app`), la cual podrás pegar directamente en la **Ficha de Entrega EC1**.
